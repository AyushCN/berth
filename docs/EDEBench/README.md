# EDEBench Dataset

This dataset contains raw performance measurements and repository profiles used to evaluate cold-start latencies in Ephemeral Development Environments (EDEs) for the Berth orchestrator.

## Structure
- `coldstart-v1.csv`: Raw execution logs of environment provisioning. Includes baseline and predictive configuration comparisons.
- `repositories.csv`: The list of open-source GitHub repositories used for training the predictive models.
- `feature-schema.json`: Schema definitions for extracted features from the codebase.

## Usage and Citation
This dataset is published via Zenodo to support Artifact Evaluation and further research in cloud-based developer environments.
