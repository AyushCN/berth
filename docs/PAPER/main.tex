\begin{abstract}
Ephemeral development environments (EDEs) allow developers to spawn cloud-based coding environments on demand. However, cold-start latency remains a significant bottleneck, often delaying productivity as repositories are cloned and dependencies installed. In this paper, we introduce Berth, a robust platform that minimizes EDE initialization time through a static prediction service and pre-warmed container pools. By analyzing repository metadata via a zero-dependency ML pipeline, Berth accurately provisions the necessary runtime before user connection. Our evaluation shows that Berth reduces cold-start latency from an average of ~30 seconds to under ~10 seconds compared to baseline provisioning, delivering a near-instant developer experience.
\end{abstract}
